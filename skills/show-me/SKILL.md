---

<!-- Inspired by HumanLayer: https://github.com/humanlayer/skills/tree/main/plugins/show-me -->

Choose the smallest visual that clarifies the user's question:
- Pseudocode for logic.
- A tree for calls, components, or files.
- Mermaid for interactions and data flow.
- A diff for changes.
- A focused HTML artifact for richer layouts or comparisons.

Use real names and relevant context. Include only details needed to
understand the point. Keep accompanying prose brief. If creating an
HTML artifact, provide a link or open it with available tools.
